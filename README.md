# 📂 File Share System

[![Powered by Aman Projects](https://img.shields.io/badge/Powered%20by-Aman%20Projects-blue.svg)](https://amanprojects.com)

A sleek, fast, and secure PHP-based file sharing system. This application allows users to easily upload, manage, and share files via unique download links.

## ✨ Features

- **Easy File Uploads:** Simple interface for uploading files of various formats.
- **Secure Downloads:** Generates unique links for downloading files securely.
- **Lightweight & Fast:** Built with core PHP for maximum performance.
- **Responsive Design:** Works seamlessly on desktops, tablets, and mobile devices.

## 🚀 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/amanprojects-ops/quick-file-transfer.git
   ```
2. **Setup the server:**
   Place the project files in your web server's root directory (e.g., `htdocs` for XAMPP, `www` for WAMP/LAMP).
3. **Configure Permissions:**
   Ensure your target upload directory has write permissions so the script can save files.
4. **Access the application:**
   Open your browser and navigate to `http://localhost/file-share-system`.

## 💻 Usage

1. Go to the homepage (`index.php`).
2. Select a file from your device and click **Upload**.
3. Copy the generated shareable link.
4. Share the link with others so they can download the file via `download.php`.

## 🛠️ Built With

- **PHP** - Backend logic and file handling
- **HTML/CSS/JS** - Frontend user interface
